# ahk-macro-recorder
An AutoHotkey v2 macro recorder with humanized playback and GUI
## How to use

1. Install AutoHotkey v2
2. Run `ahk-recorder.ahk`
3. Use F9 to record / F10 to play back (etc…)

## Features

- Smart mouse movement
- Humanized playback
- Emergency stop
- Persistent settings
- GUI controls
